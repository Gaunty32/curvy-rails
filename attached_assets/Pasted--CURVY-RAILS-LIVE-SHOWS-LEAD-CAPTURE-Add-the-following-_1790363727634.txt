# CURVY RAILS — LIVE SHOWS & LEAD CAPTURE

Add the following requirements to the Curvy Rails / Whatnot architecture.

The existing Curvy Rails Whatnot operation runs a substantial programme of live shows.

Examples include:

* Preloved Power Hour — Size 16–18
* Preloved Power Hour — Size 20–22
* Preloved Power Hour — Size 24+
* Brand New With Tags
* Coat Show
* Loungewear
* themed/specialist shows

The website should make these live shows a significant part of the Curvy Rails experience.

The objective is NOT to reproduce Whatnot.

The objectives are:

1. Promote upcoming Curvy Rails live shows.
2. Send people to Whatnot to watch/buy.
3. Encourage visitors to register for future show alerts.
4. Capture first-party customer data.
5. Convert the Whatnot audience into Curvy Rails community members.
6. Attribute those people and subsequent website sales back to Whatnot/live activity.

* artwork

# 6. MAKE LEAD CAPTURE SITE-WIDE

Do not restrict this form to /live.

Create reusable components so the same lead-capture opportunity can appear appropriately on:

* homepage
* /live
* show pages
* footer
* community pages
* relevant landing pages

Do NOT bombard visitors with constant popups.

The experience should feel like:

**Join us**

rather than:

**Give us your data.**

Allow someone to express interest in a PARTICULAR show.

For example:

**REMIND ME ABOUT THIS SHOW →**

Ask for:

Name
Email
Mobile

plus appropriate communication choices.

customer/contact

show

registration timestamp

source

communication preference/permission

This creates useful intent data.

# 15. DO NOT SCRAPE WHATNOT

For the first implementation, do NOT attempt to scrape the Whatnot website to obtain upcoming shows.

Admin should enter/manage shows within Curvy Rails.

Design the integration layer so that if Whatnot later provides an appropriate authenticated method of retrieving show information, this can replace or supplement manual management.

Do not make the Live experience dependent upon undocumented Whatnot functionality.

---

# 16. CRM PRINCIPLE

The commercial objective behind Live is important.

WHATNOT FOLLOWER

is useful.

But:

CURVY RAILS CONTACT

with appropriate first-party:

Name
Email
Mobile
Preferences
Consent
Behaviour
Community membership
Website purchase history

is considerably more useful to Curvy Rails.

Therefore every Live page should gently create opportunities to:

# JOIN THE RAILS

or:

# BE FIRST TO KNOW

without making the experience feel like a lead-generation funnel.

---

# 17. IMPORTANT USER EXPERIENCE PRINCIPLE

Do not use corporate CRM terminology on the public website.

Never show:

"Lead capture"

"Marketing database"

"Submit details"

"CRM"

Instead use Curvy Rails language:

**Be first to know**

**Keep me in the loop**

**Remind me**

**Join the Rails**

**Don't let me miss it**

**Tell me when you're live**

The technology can behave like a sophisticated CRM funnel.

The customer experience must feel like joining a community.
